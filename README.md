# Git Sandbox

AI クラウドエージェント(Claude Code など)が自由に試行錯誤するためのサンドボックス用リポジトリです。

## 自由に使ってOK

- このリポジトリの中身は **すべて自由に作成・変更・削除してかまいません**。
- 作業は **ブランチを切って** 行ってください。`master` に直接 push しないでください。
- ブランチ名の例: `claude/<topic>`, `sandbox/<topic>`, `experiment/<date>`
- 失敗しても問題ありません。不要になったブランチは削除して構いません。
- 過去の C++ サンプル(`DiceGame.cpp`, `howOld.cpp`)は削除済みですが、Git 履歴から参照できます。

## エージェント向けの流れ

1. `master` から新しいブランチを作る
2. 好きなコード・ファイルを追加して試す
3. 変更をコミットして、そのブランチに push する
4. Pull Request は、ユーザーから頼まれたときだけ作る

詳しいルールは [AGENTS.md](./AGENTS.md) を参照してください。
