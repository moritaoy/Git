# portfolio

守田 一喜 (@moritaoy) のポートフォリオサイト試作。青空テーマ × ゲーム風演出で 3 パターン。

| パターン | ディレクトリ | コンセプト |
| --- | --- | --- |
| A. SKY STATUS | `a-sky-status/` | RPG のステータス/メニュー画面風。経歴はクエストログ |
| B. FLIGHT LOG | `b-flight-log/` | フライト HUD 風。スクロールで高度が上がり空の色が変わる |
| C. PIXEL SKY | `c-pixel-sky/` | ドット絵レトロゲーム風。紙飛行機のミニゲーム付き |

- どれも `index.html` 1 ファイルで完結(ビルド不要、外部依存は Google Fonts のみ)。ブラウザで直接開けます。
- 掲載内容は各ファイルの `<script>` 冒頭にある `PROFILE` オブジェクトを編集すれば差し替えられます。
- `screenshots/` に PC / スマホ表示のキャプチャがあります。
